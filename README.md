# Decal Forge

Desktop-приложение для подготовки декалей: PNG → векторный SVG, удаление однотонного фона и нарезка trim sheets. Обработка локальная, интернет при работе не нужен.

## Запуск

Откройте `dist/1.1.0/DecalForge-win32-x64/DecalForge.exe`. Переносите всю папку приложения вместе с EXE. Версия 1.0 остаётся в прежней папке; уже открытое старое окно не обновляется автоматически.

## Что исправлено в 1.1

- Сплошная заливка строится по отдельному силуэту альфа-канала. Упрощение цветных областей не создаёт внутри него прозрачных провалов. Реальные отверстия сохраняются, а цветные контуры ограничиваются силуэтом.
- Фильтр мелких пятен объединяет их с соседним цветом вместо удаления. Порог теперь измеряется в пикселях площади; он не влияет на прозрачность.
- Новая палитра учитывает распределение цветов, включая небольшие цветные акценты. Добавлено упрощение фактуры с сохранением контрастных границ.
- Профиль «Геометрия декали» по умолчанию: 16 цветов, высокая точность, слабое упрощение, объединение пятен до 4 пикселей. На небольших картинках не увеличивайте упрощение без проверки: оно может удалить тонкую линию или маленькую букву.
- Для знаков и текста используйте «Логотип / текст». Для сохранения потёртостей — «Сохранить фактуру». Все настройки можно менять вручную.

## Работа

1. Откройте PNG кнопкой, через Ctrl+O или перетащите файл в окно.
2. При необходимости включите удаление фона. Выберите цвет пипеткой, настройте допуск. Режим «Только фон от краёв» сохраняет замкнутые внутренние участки того же цвета; выключите его для удаления выбранного цвета везде. Исходник хранится в памяти, восстановление не затрагивает выделения.
3. Протяните мышью прямоугольник вокруг каждой детали. Можно выделять пересекающиеся области. Координаты X/Y и размеры Ш/В редактируются в списке справа, единицы — пиксели исходного PNG. Масштаб просмотра не меняет экспорт.
4. Задайте имена файлов и настройки SVG. Цветной режим сохраняет ограниченную палитру; режим маски оставляет тёмные пиксели чёрными, светлые делает прозрачными. Порог прозрачности превращает альфу SVG в чёткую границу. PNG сохраняет исходную полупрозрачность оставшихся пикселей.
5. Нажмите «Предпросмотр SVG» для выбранного фрагмента. Если фрагментов нет, показывается всё изображение.
6. Экспортируйте SVG в папку. Все выделения сохраняются отдельными файлами. Без выделений экспортируется исходный размер целиком. Опция PNG добавляет вырезанные растровые версии с альфой. При совпадении имени добавляется числовой суффикс, старые файлы сохраняются.

Delete удаляет выбранный фрагмент. Escape отменяет текущее выделение или пипетку и возвращает изображение.

## Ограничения

- Удаляется однотонный фон по цвету, не произвольный фотографический фон.
- Векторизация предназначена прежде всего для логотипов, надписей, силуэтов и графических декалей. Фотографии, шум и PBR-текстуры не сохраняются без потерь. Для них предусмотрен PNG.
- SVG содержит реальные контуры, без встроенного растрового изображения. Цвета группируются в палитру; мелкие цветные области можно сохранять или объединять с соседними.
- Защита заливки сохраняет альфа-силуэт после удаления фона и применения порогов. Если фон по ошибке удалён внутри детали, отключите удаление фона: векторизация не восстанавливает уже удалённые пиксели. Неровный обрезанный край сохраняется, скрытая за обрезкой геометрия не достраивается.
- PNG-экспорт сохраняет растр после удаления фона и обрезки. Упрощение фактуры относится к SVG, а не к PNG.
- Лимит PNG: 100 МБ / 25 мегапикселей. Сложные большие изображения могут обрабатываться долго, особенно с палитрой 64 цвета.
- Выделения сохраняются в текущей сессии; файлов проекта, перемещения прямоугольников мышью и отмены последнего действия пока нет. Положение и размеры меняются численно.
- Сборка Windows x64 переносимая, без установщика и цифровой подписи.

## Разработка

Нужны Windows x64, Node.js 22.12+ (или 24 LTS) и npm. После клонирования репозитория:

```powershell
npm ci
node node_modules/electron/install.js
npm start
npm test
npm run test:smoke
npm run package
```

Готовая сборка появится в `dist/1.1.0/DecalForge-win32-x64`. Папки `node_modules`, `dist` и `test-output` не хранятся в Git и создаются локально.

Основные файлы: `main.cjs` — файловые диалоги и безопасная запись; `renderer.js` — интерфейс и выделения; `core.js` — обработка фона; `tracing.js` и `trace-worker.js` — трассировка вне UI-потока. Контуры строятся библиотекой ImageTracerJS (public domain). Electron и зависимости поставляются с собственными лицензиями.

`node --test tests/core.test.cjs` проверяет фон, альфа-канал, отверстия, координаты и воспроизводимость SVG. `tests/examples.test.cjs` растеризует все примеры через Sharp и проверяет покрытие. `npm run test:smoke` проверяет реальный Electron-сценарий, профили и альфа-канал примера в Chromium с тестовыми диалогами. Sharp и Playwright устанавливаются как зависимости разработки; отдельная установка браузеров Playwright не требуется.
